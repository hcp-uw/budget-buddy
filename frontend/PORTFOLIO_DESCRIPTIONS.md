### Full Description:

I developed Budget Buddy, a full-stack web application that transforms personal finance management into an engaging game-like experience. This project combines modern web technologies with financial data integration to help users track spending, set budgets, and achieve financial goals through gamification mechanics.

Integrated Supabase (PostgreSQL) for robust data persistence, implementing proper database schema design for users, transactions, budgets, and gamification metrics.

**Key Features:**
- Complete multi-step user authentication with email-based account creation and Plaid bank linking
- Real-time transaction fetching and automated spending calculations from actual bank data
- Interactive dashboard displaying current spending, budget progress, and financial metrics
- Responsive design optimized for various screen sizes with pixel-art UI components

**Outcome:**
This project demonstrates full-stack development capabilities including OAuth2 integration, RESTful API design, real-time data processing, and modern frontend architecture. It showcases ability to work with third-party financial APIs, manage sensitive financial data responsibly, and create engaging user experiences that encourage behavioral change.

**Skills Applied:**
React • TypeScript • Express.js • RESTful APIs • Plaid API Integration • Supabase • PostgreSQL • Frontend Architecture • UI/UX Design • Authentication Flows

## 📋 Interview Talking Points

**If asked "Tell us about your biggest project":**
"I built Budget Buddy, a full-stack web application that combines personal finance with gamification. The biggest technical challenge was securely integrating the Plaid API to fetch real transaction data without storing sensitive credentials - I solved this by implementing OAuth2 flow on the backend. I also had to design the database schema thoughtfully to model transactions, budgets, and user data while maintaining data integrity. The frontend features real-time calculations showing users their actual spending rather than estimates. The whole stack is TypeScript for type safety, React for the interactive UI, Express for the API, and Supabase for the database."

**If asked "What would you add next":**

I'd also implement more advanced analytics showing spending trends, predictive budgeting, and personalized recommendations. On the technical side, I'd add automated testing, implement caching for better performance, and set up CI/CD for continuous deployment."
